# 데일리체크 (DailyCheck) — MVP 1단계

기획서: [기획서.md](기획서.md)

## 실행

```bash
npm install
npm run dev        # 개발 서버 (같은 와이파이의 핸드폰에서 http://<PC IP>:5173 으로 접속 가능)
npm run build      # 배포용 빌드 → dist/
```

## 지금 되는 것 (기획서 3장 «핵심 1단계»)

| 기능 | 상태 |
|---|---|
| 점검표 만들기 — 항목 추가·삭제·수정·순서 변경 | ✅ |
| 입력 유형: 예/아니오 · 숫자(기준 이상/이하) · 선택지 · 메모 · 사진 | ✅ |
| 이상 판정: 예/아니오의 «정상 답», 숫자 기준값, «이상 선택지» | ✅ |
| 모바일 입력: 큰 버튼, 진행률, 필수 항목 누락 표시, 이름 기억 | ✅ |
| 오프라인: 기기 안(IndexedDB)에 저장, 앱 화면은 PWA로 캐시 | ✅ |
| 입력 도중 앱이 꺼져도 임시 저장본으로 이어 쓰기 | ✅ |
| 날짜별 기록 조회·수정·삭제 | ✅ |
| CSV 내보내기 (엑셀 / 구글 시트 «파일 › 가져오기») | ✅ |
| 월간 보고서: 요약 문장, 점검 달력, 항목별 합계·평균·추이 그래프, 이상 목록, 인쇄/PDF | ✅ |
| 업종 템플릿: 설비 일일점검, HACCP 일반위생관리 일지 | ✅ (2단계 맛보기) |
| **서버(Supabase) 동기화 · 로그인 · 회사별 데이터 분리** | ❌ 다음 단계 |

## 구조

- `src/types.ts` — 데이터 구조 (Supabase 표로 옮기기 쉽게 설계, `synced` 필드로 동기화 대기 표시)
- `src/db.ts` — 기기 내 저장소 (Dexie/IndexedDB)
- `src/pages/Inspect.tsx` — 현장 입력 화면
- `src/pages/Report.tsx` — 월간 보고서
- `src/pages/ChecklistEditor.tsx` — 점검표 편집
- `src/templates.ts` — 업종별 서식 템플릿

## 주의

- 지금은 데이터가 **그 기기의 브라우저 안에만** 있습니다. 브라우저 데이터를 지우면 기록이 사라집니다. 여러 직원이 같이 쓰려면 Supabase 연결이 필요합니다.
- 핸드폰 카메라·«홈 화면에 추가»(PWA 설치)는 https 주소에서만 제대로 동작합니다. (localhost 제외)
