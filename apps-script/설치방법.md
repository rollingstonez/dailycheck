# 구글 시트 연결 방법 (10분, 한 번만)

## 1. 시트 준비

탭 하나가 점검표 하나입니다. 예시: [예시_시트.csv](예시_시트.csv) (구글 시트 › 파일 › 가져오기 로 열 수 있음)

| 점검사항 | 기준 | 11/24 | 11/25 |
|---|---|---|---|
| 밸브 | on/off | on | off |
| 오일 (ml) | 100~150 | 120 | 130 |
| 헬륨 (kg) | 40 이상 | 45 | 42 |
| 온도 (℃) | 95 이하, 사진 | 85 | 86 |
| 특이사항 | | | |

- **A열 점검사항**: 단위는 괄호에 → `오일 (ml)` 은 앱에서 `[오일] [(ml)] [   ]` 로 보입니다.
- **B열 기준** (1행 제목이 «기준»일 때만 인식, 없어도 됨)
  - `on/off`, `up/down`, `예/아니오`, `O/X` → 버튼으로 입력. **앞에 쓴 것이 정상**, 뒤는 이상으로 표시
  - `100~150`, `40 이상`, `95 이하` → 숫자 입력, 벗어나면 이상으로 표시
  - `사진` 을 함께 쓰면 (예: `95 이하, 사진`) 그 항목에 사진 버튼이 생깁니다
  - 비워 두면: 단위가 있으면 숫자, 지금까지 적힌 값이 on/off 같은 글자면 버튼, 아니면 메모
- **1행 날짜**: 앱에서 저장하면 그날 열이 없을 경우 날짜 순서에 맞게 자동으로 추가됩니다.
- 맨 아래 **점검자 / 점검시각** 행은 앱이 자동으로 만듭니다.
- 탭 이름이 `_` 로 시작하거나 숨긴 탭은 앱에 나타나지 않습니다.

## 2. 스크립트 붙여 넣기

1. 시트 메뉴 **확장 프로그램 › Apps Script**
2. 원래 있던 내용을 모두 지우고 [Code.gs](Code.gs) 내용을 통째로 붙여 넣기
3. 맨 위 `var TOKEN = '1234';` 의 `1234` 를 원하는 비밀번호로 바꾸기
4. 💾 저장

## 3. 배포 (주소 만들기)

1. 오른쪽 위 **배포 › 새 배포**
2. 톱니바퀴 › **웹 앱** 선택
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 권한 검토 › 내 계정 선택 › «고급» › «(안전하지 않음)으로 이동» › 허용
   (내가 만든 스크립트라 구글이 검증하지 않았다는 뜻입니다. 시트와 드라이브 사진 폴더에만 접근합니다)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

## 4. 앱에 연결

데일리체크 앱 › **점검표** 탭 › «구글 시트 연결» 에 URL 과 비밀번호를 넣고 «연결».

## 5. 월간 보고서 (시트 안에 자동으로)

시트를 새로 열면 위쪽 메뉴에 **데일리체크** 가 생깁니다. (처음 한 번은 권한 허용 창이 뜹니다)

| 메뉴 | 하는 일 |
|---|---|
| 이번 달 보고서 만들기 | 점검표 탭마다 «_월간 2026-11 탭이름» 탭을 만들거나 새로 고침 |
| 지난달 보고서 만들기 | 지난달 것 |
| 매일 아침 보고서 자동 갱신 켜기 | 매일 아침 6시쯤 이번 달 보고서를 자동으로 새로 고침. 매월 1~3일에는 지난달 보고서도 마무리 |
| 자동 갱신 끄기 | 위 자동 실행 중지 |

앱의 **보고서 › 월간** 화면에서 «11월 보고서 탭 만들기» 버튼으로도 만들 수 있습니다.

보고서 탭 내용: 요약(점검률 · 빠진 평일 · 이상 건수 · 사진 수 · 눈에 띄는 변화) → 항목별 요약 표 → 이상 · 사진 목록 → 날짜별 값 표 → 오른쪽에 숫자 항목별 선 그래프.

**구글 슬라이드에 붙이기**: 보고서 탭의 그래프 클릭 › 복사 › 슬라이드에 붙여넣기 › «스프레드시트에 연결» 선택.
보고서를 다시 만들어도 그래프는 지우지 않고 고쳐 쓰므로, 슬라이드에서 그래프 위 «업데이트» 버튼만 누르면 최신 숫자로 바뀝니다.

## 6. 사진이 시트에 보이는 방식

현장에서 «어? 이상한데» 싶으면 어느 항목에서나 📷 를 누를 수 있고, 점검표에 없는 것은 화면 아래 «점검표에 없는 이상 발견» 에서 찍습니다.

1. **점검표 칸**: 값은 그대로 두고 칸 배경만 연한 주황. 칸 메모(노트)에 «📷 사진 N장 · 점검자 시각», 한 줄 설명, 사진 링크
2. **«_사진기록» 탭**: 사진 한 장 = 한 줄 (날짜 · 시각 · 점검표 · 항목 · 그때 값 · 메모 · 점검자 · 칸 안 미리보기 · 원본 «열기»)
3. **드라이브**: «데일리체크 사진 / 탭이름 / 2026-11» 폴더에 원본 (날짜 · 시간 · 점검자 워터마크)
4. 점검표에 «특이사항» 행이 없으면 처음 «이상 발견» 을 저장할 때 점검자 행 위에 자동으로 생깁니다.

사진은 외부에 공개되지 않습니다. 미리보기는 스크립트가 그림을 칸 안에 직접 넣는 방식입니다.

## 알아 둘 것

- 현장 직원은 구글 계정이 없어도 됩니다. 스크립트가 시트 주인 권한으로 기록합니다.
- 이름이 `_` 로 시작하는 탭(«_사진기록», «_월간 …»)은 앱의 점검표 목록에 나오지 않습니다.
- 인터넷이 없을 때 입력한 것은 휴대폰에 보관했다가 연결되면 자동으로 시트에 들어갑니다.
- 시트에서 항목을 추가·수정하면 앱에서 «지금 동기화» 후 반영됩니다.
- **스크립트를 고친 뒤에는** 배포 › 배포 관리 › ✏️ › 버전: 새 버전 › 배포 (주소는 그대로 유지됨)
- **2026-11-26 이전에 설치했다면**: Code.gs 내용을 새것으로 통째로 바꿔 붙이고(맨 위 TOKEN 비밀번호는 원래 값으로) › 저장 › 위처럼 새 버전 배포 › 시트 새로 고침. 새 기능(보고서 메뉴·자동 갱신)용 권한 허용 창이 한 번 더 뜹니다.
- 비밀번호를 아는 사람만 기록할 수 있습니다. 주소와 비밀번호를 외부에 공유하지 마세요.
