# 구글 시트 연결 방법 (10분, 한 번만)

## 1. 시트 준비

탭 하나가 점검표 하나입니다. 예시: [예시_시트.csv](예시_시트.csv) (구글 시트 › 파일 › 가져오기 로 열 수 있음)

| 점검사항 | 기준 | 11/24 | 11/25 |
|---|---|---|---|
| 밸브 | on/off | on | off |
| 오일 (ml) | 100~150 | 120 | 130 |
| 헬륨 (kg) | 40 이상 | 45 | 42 |
| 온도 (℃) | 95 이하, 사진 | 85 | 86 |
| 특이사항 | | | |

- **A열 점검사항**: 단위는 괄호에 → `오일 (ml)` 은 앱에서 `[오일] [(ml)] [   ]` 로 보입니다.
- **B열 기준** (1행 제목이 «기준»일 때만 인식, 없어도 됨)
  - `on/off`, `up/down`, `예/아니오`, `O/X` → 버튼으로 입력. **앞에 쓴 것이 정상**, 뒤는 이상으로 표시
  - `100~150`, `40 이상`, `95 이하` → 숫자 입력, 벗어나면 이상으로 표시
  - `사진` 을 함께 쓰면 (예: `95 이하, 사진`) 그 항목에 사진 버튼이 생깁니다
  - 비워 두면: 단위가 있으면 숫자, 지금까지 적힌 값이 on/off 같은 글자면 버튼, 아니면 메모
- **1행 날짜**: 앱에서 저장하면 그날 열이 없을 경우 날짜 순서에 맞게 자동으로 추가됩니다.
- 맨 아래 **점검자 / 점검시각** 행은 앱이 자동으로 만듭니다.
- 탭 이름이 `_` 로 시작하거나 숨긴 탭은 앱에 나타나지 않습니다.

## 2. 스크립트 붙여 넣기

1. 시트 메뉴 **확장 프로그램 › Apps Script**
2. 원래 있던 내용을 모두 지우고 [Code.gs](Code.gs) 내용을 통째로 붙여 넣기
3. 맨 위 `var TOKEN = '1234';` 의 `1234` 를 원하는 비밀번호로 바꾸기
   - (선택) 바로 아래 `var ADMIN_PIN = '';` 은 **승인 비밀번호**입니다. 혼자 쓰시면 비워 두세요(승인 버튼만 누르면 됨). 직원도 같이 쓰고 점검표 변경은 나만 승인하고 싶다면 숫자 4~6자리를 넣으세요.
4. 💾 저장

## 3. 배포 (주소 만들기)

1. 오른쪽 위 **배포 › 새 배포**
2. 톱니바퀴 › **웹 앱** 선택
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 권한 검토 › 내 계정 선택 › «고급» › «(안전하지 않음)으로 이동» › 허용
   (내가 만든 스크립트라 구글이 검증하지 않았다는 뜻입니다. 시트와 드라이브 사진 폴더에만 접근합니다)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

## 4. 앱에 연결

데일리체크 앱 › **점검표** 탭 › «구글 시트 연결» 에 URL 과 비밀번호를 넣고 «연결».

## 점검항목을 바꾸고 싶을 때 (변경 확인)

1. **시트에서** 행을 추가·삭제·수정합니다. (기준 열을 고쳐도 됩니다)
2. 앱 «오늘» 화면에 **«⚠ 시트의 점검항목이 바뀌었습니다»** 가 뜹니다. 눌러서 추가·삭제·이름 변경·기준 변경 내용을 확인합니다.
3. **«승인하고 반영»** (승인 비밀번호를 정했다면 비밀번호 입력) → 모든 폰의 화면에 반영됩니다.

- 승인하기 전까지는 직원들이 **이전에 확정한 점검표로 계속 입력**합니다. 실수로 지운 행이 바로 현장 화면에서 사라지지 않습니다.
- 처음 연결할 때의 시트 모양은 자동으로 확정됩니다. 시트에 숨김 탭 «_승인본» 이 생기는데, **지우지 마세요.** (지우면 그때의 시트 모양이 새 기준으로 다시 확정됩니다)
- 행을 **삭제하면 그 행의 과거 기록도 시트에서 사라집니다.** 실수였다면 승인하지 말고 시트에서 되돌리세요(Ctrl+Z 또는 파일 › 버전 기록).
- 새 탭을 만들면 «새 점검표»로 승인 대상에 나타납니다.

## 입력한 값은 잠깁니다 (정정)

- 앱에서 저장하기 전에 **확인 화면**이 나오고, 저장하면 그 값은 **잠깁니다.** (오늘 입력한 값도 마찬가지) 비어 있는 항목만 이어서 입력할 수 있습니다.
- 값을 고치려면 칸 옆의 **«정정»** → 새 값 + **사유(필수)** (+ 승인 비밀번호를 정했다면 비밀번호). 정정에는 인터넷이 필요합니다.
- 정정해도 **원본은 지워지지 않습니다.** 시트의 숨김 탭에 남습니다.
  - «_기록»: 입력·정정이 일어난 순서대로 한 줄씩 덧붙는 장부 (시각, 구분, 항목, 값, 이전값, 사유, 점검자)
  - «_정정»: 정정 내역만 따로 (앱이 읽어서 «✎ 정정됨»으로 표시)
  - 정정한 칸에는 메모로 «정정 시각: 원본 → 정정값 (사유)» 가 붙습니다.
- 이미 기록된 칸은 **스크립트가 덮어쓰지 않습니다.** (예전 앱이나 다른 폰에서 같은 칸에 다른 값이 와도 거부) 값은 «정정»으로만 바뀝니다.
- 이 숨김 탭들은 지우지 마세요. 장부를 지우면 흔적이 사라집니다.
- ⚠ 시트 주인은 구글 시트에서 직접 무엇이든 고칠 수 있습니다. 앱은 이를 막지는 못합니다. (직접 수정 감지·시트 보호는 다음 단계)

## 알아 둘 것

- 현장 직원은 구글 계정이 없어도 됩니다. 스크립트가 시트 주인 권한으로 기록합니다.
- 사진은 내 구글 드라이브 «데일리체크 사진 / 탭이름» 폴더에 저장되고, 시트 칸에 메모(노트)로 링크가 붙습니다.
- 인터넷이 없을 때 입력한 것은 휴대폰에 보관했다가 연결되면 자동으로 시트에 들어갑니다.
- 시트에서 고친 점검항목은 «변경 확인»에서 승인하면 반영됩니다. (위 설명 참고)
- **스크립트를 고친 뒤에는** 배포 › 배포 관리 › ✏️ › 버전: 새 버전 › 배포 (주소는 그대로 유지됨)
- 비밀번호를 아는 사람만 기록할 수 있습니다. 주소와 비밀번호를 외부에 공유하지 마세요.
