# 구글 시트 연결 방법 (10분, 한 번만)

## 1. 시트 준비

탭 하나가 점검표 하나입니다. 예시: [예시_시트.csv](예시_시트.csv) (구글 시트 › 파일 › 가져오기 로 열 수 있음)

| 점검사항 | 기준 | 11/24 | 11/25 |
|---|---|---|---|
| 밸브 | on/off | on | off |
| 오일 (ml) | 100~150 | 120 | 130 |
| 헬륨 (kg) | 40 이상 | 45 | 42 |
| 온도 (℃) | 95 이하, 사진 | 85 | 86 |
| 특이사항 | | | |

- **A열 점검사항**: 단위는 괄호에 → `오일 (ml)` 은 앱에서 `[오일] [(ml)] [   ]` 로 보입니다.
- **B열 기준** (1행 제목이 «기준»일 때만 인식, 없어도 됨)
  - `on/off`, `up/down`, `예/아니오`, `O/X` → 버튼으로 입력. **앞에 쓴 것이 정상**, 뒤는 이상으로 표시
  - `100~150`, `40 이상`, `95 이하` → 숫자 입력, 벗어나면 이상으로 표시
  - `사진` 을 함께 쓰면 (예: `95 이하, 사진`) 그 항목에 사진 버튼이 생깁니다
  - 비워 두면: 단위가 있으면 숫자, 지금까지 적힌 값이 on/off 같은 글자면 버튼, 아니면 메모
- **1행 날짜**: 앱에서 저장하면 그날 열이 없을 경우 날짜 순서에 맞게 자동으로 추가됩니다.
- 맨 아래 **점검자 / 점검시각** 행은 앱이 자동으로 만듭니다.
- 탭 이름이 `_` 로 시작하거나 숨긴 탭은 앱에 나타나지 않습니다.

## 2. 스크립트 붙여 넣기

1. 시트 메뉴 **확장 프로그램 › Apps Script**
2. 원래 있던 내용을 모두 지우고 [Code.gs](Code.gs) 내용을 통째로 붙여 넣기
3. 맨 위 `var TOKEN = '1234';` 의 `1234` 를 원하는 비밀번호로 바꾸기
   - (선택) 바로 아래 `var ADMIN_PIN = '';` 은 **승인 비밀번호**입니다. 혼자 쓰시면 비워 두세요(승인 버튼만 누르면 됨). 직원도 같이 쓰고 점검표 변경은 나만 승인하고 싶다면 숫자 4~6자리를 넣으세요.
4. 💾 저장

## 3. 배포 (주소 만들기)

1. 오른쪽 위 **배포 › 새 배포**
2. 톱니바퀴 › **웹 앱** 선택
3. 실행 사용자: **나**, 액세스 권한: **모든 사용자**
4. **배포** → 권한 검토 › 내 계정 선택 › «고급» › «(안전하지 않음)으로 이동» › 허용
   (내가 만든 스크립트라 구글이 검증하지 않았다는 뜻입니다. 시트와 드라이브 사진 폴더에만 접근합니다)
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`) 복사

## 4. 앱에 연결

데일리체크 앱 › **점검표** 탭 › «구글 시트 연결» 에 URL 과 비밀번호를 넣고 «연결».

## 한 달에 탭 하나씩 쓰기 (월별 탭)

달이 바뀔 때마다 탭을 늘려 쓰는 현장 방식을 그대로 쓸 수 있습니다. **이름이 같고 월만 다른 탭은 앱에서 하나의 점검표**로 보입니다.

```
시트 탭:  설비점검 2026-11 │ 설비점검 2026-12 │ 보일러실 2026-11 │ ...
앱 화면:  [설비점검]  [보일러실]
```

- **권장 탭 이름: `점검표이름 2026-11`** (예: `설비점검 2026-11`). 앱은 `설비점검 2026.11`, `2026년 11월`, `26년 11월`, `설비점검 11월`, `11월`도 읽습니다. 월이 없는 이름은 지금처럼 탭 하나가 점검표 하나입니다.
- **입력은 그 날짜가 속한 달의 탭**에 들어갑니다. (지난 날짜를 뒤늦게 입력해도 그 달 탭)
- **새 달의 첫 입력 때 새 탭이 자동으로 만들어집니다.** 지난달 탭을 복사하고 날짜별 값만 비웁니다. 점검사항·기준·서식은 그대로 이어지고, 변경 승인도 다시 묻지 않습니다. 손으로 탭을 복사해 만들어도 같습니다. (지난달과 똑같으면 자동 확정, 항목을 바꿨으면 «변경 확인»에 지난달과 달라진 점만 나타납니다)
- 새 달 탭이 아직 없어도 입력할 수 있습니다. 지난달의 확정된 항목으로 입력 화면이 뜨고, 저장할 때 탭이 만들어집니다. (오프라인이어도 마찬가지)
- **다음 달 탭을 미리 만들어 두어도** 이번 달 입력은 이번 달 탭의 항목으로 합니다.
- **보고서·기록**은 여러 달의 탭을 합쳐서 보여 줍니다. (주간 보고서가 달을 넘어도 하나로 나옵니다)
- 동기화는 **최근 3개월 탭**만 읽습니다. 그보다 오래된 달은 보고서·기록에서 그 달을 열 때 불러옵니다. (탭이 해마다 쌓여도 느려지지 않도록) 기록 검사도 기본은 최근 3개월이고, «전체 기간 검사»로 모두 볼 수 있습니다.
- 탭 이름을 중간에 바꾸면 앱은 다른 점검표로 봅니다. 이름 규칙은 처음에 정해 두세요.

## 점검항목을 바꾸고 싶을 때 (변경 확인)

1. **시트에서** 행을 추가·삭제·수정합니다. (기준 열을 고쳐도 됩니다)
2. 앱 «오늘» 화면에 **«⚠ 시트의 점검항목이 바뀌었습니다»** 가 뜹니다. 눌러서 추가·삭제·이름 변경·기준 변경 내용을 확인합니다.
3. **«승인하고 반영»** (승인 비밀번호를 정했다면 비밀번호 입력) → 모든 폰의 화면에 반영됩니다.

- 승인하기 전까지는 직원들이 **이전에 확정한 점검표로 계속 입력**합니다. 실수로 지운 행이 바로 현장 화면에서 사라지지 않습니다.
- 처음 연결할 때의 시트 모양은 자동으로 확정됩니다. 시트에 숨김 탭 «_승인본» 이 생기는데, **지우지 마세요.** (지우면 그때의 시트 모양이 새 기준으로 다시 확정됩니다)
- 행을 **삭제하면 그 행의 과거 기록도 시트에서 사라집니다.** 실수였다면 승인하지 말고 시트에서 되돌리세요(Ctrl+Z 또는 파일 › 버전 기록).
- 새 탭을 만들면 «새 점검표»로 승인 대상에 나타납니다.

## 입력한 값은 잠깁니다 (정정)

- 앱에서 저장하기 전에 **확인 화면**이 나오고, 저장하면 그 값은 **잠깁니다.** (오늘 입력한 값도 마찬가지) 비어 있는 항목만 이어서 입력할 수 있습니다.
- 값을 고치려면 칸 옆의 **«정정»** → 새 값 + **사유(필수)** (+ 승인 비밀번호를 정했다면 비밀번호). 정정에는 인터넷이 필요합니다.
- 정정해도 **원본은 지워지지 않습니다.** 시트의 숨김 탭에 남습니다.
  - «_기록»: 입력·정정이 일어난 순서대로 한 줄씩 덧붙는 장부 (시각, 구분, 항목, 값, 이전값, 사유, 점검자)
  - «_정정»: 정정 내역만 따로 (앱이 읽어서 «✎ 정정됨»으로 표시)
  - 정정한 칸에는 메모로 «정정 시각: 원본 → 정정값 (사유)» 가 붙습니다.
- 이미 기록된 칸은 **스크립트가 덮어쓰지 않습니다.** (예전 앱이나 다른 폰에서 같은 칸에 다른 값이 와도 거부) 값은 «정정»으로만 바뀝니다.
- 이 숨김 탭들은 지우지 마세요. 장부를 지우면 흔적이 사라집니다.
- ⚠ 시트 주인은 구글 시트에서 직접 무엇이든 고칠 수 있습니다. 완전히 막을 수는 없어서, **고치면 흔적이 남고 알려 주는 방식**입니다. (아래 «기록 검사»·«시트 보호»)

## 기록 검사 — 시트에서 직접 바뀐 값 찾기

앱을 거치지 않고 시트에서 직접 고치거나 지우면, 앱이 **«앱이 남긴 장부(_기록)»와 시트의 현재 값을 비교**해서 알려 줍니다.

- 앱을 쓰면 **6시간마다 자동으로** 검사하고, 다른 점이 있으면 «오늘» 화면에 **«⚠ 시트에서 직접 바뀐 기록이 있습니다»** 가 뜹니다. (점검표 탭 › «기록 검사»에서 언제든 «지금 검사»)
- 찾는 것: 값이 바뀜 · 값이 지워짐 · 장부에 없는 값이 직접 입력됨 · 점검항목 행/날짜 열/탭이 지워짐
- 각 건마다 선택합니다.
  - **되돌리기**: 장부에 남은 값으로 시트를 복구합니다. (지워진 행·날짜 열도 값과 함께 복구. 지워진 행은 «점검자» 행 바로 위에 다시 만들어지므로 위치는 직접 옮겨 주세요.) 바뀐 값은 장부에 «이전값»으로 남습니다.
  - **인정**: 시트의 값이 맞다고 확인하고 **사유**를 남깁니다. 장부에 «직접수정 확인»으로 기록되고 다시 나타나지 않습니다.
  - (승인 비밀번호를 정했다면 둘 다 비밀번호가 필요합니다)
- 삭제된 **탭**은 앱이 복구하지 못합니다. 구글 시트의 «파일 › 버전 기록»으로 복원하세요.
- 앱이 장부를 쓰기 시작한 날짜 이전의 기록(예전에 시트에 적어 둔 값)은 검사하지 않습니다.

## 시트 보호

처음 연결할 때 스크립트가 자동으로 겁니다. (점검표 탭 › «기록 검사 · 시트 보호» 에서 다시 적용 가능)

- **기록 칸(날짜 열 전체)**: «보호된 범위(경고)». 이 칸을 고치거나 이 칸이 든 행·열을 지우려 하면 구글 시트가 경고를 띄웁니다. 시트 주인도 마찬가지라 실수를 한 번 막아 줍니다. (경고를 무시하고 진행하면 고쳐지고, 이후 «기록 검사»에 잡힙니다)
- **점검사항·기준 칸(A·B열)과 1행**: 보호하지 않습니다. 항목을 고치는 일은 평소처럼 하고, 변경 확인에서 승인합니다.
- **숨김 장부 탭**(_승인본, _기록, _정정): 시트 주인만 고칠 수 있게 잠깁니다.
- 앱이 값을 쓸 때는 경고 없이 들어갑니다.

## 월간 보고서 (시트 안에 자동으로)

시트를 새로 열면 위쪽 메뉴에 **데일리체크** 가 생깁니다. (처음 한 번은 권한 허용 창이 뜹니다)

| 메뉴 | 하는 일 |
|---|---|
| 이번 달 보고서 만들기 | 점검표 탭마다 «_월간 2026-11 탭이름» 탭을 만들거나 새로 고침 |
| 지난달 보고서 만들기 | 지난달 것 |
| 매일 아침 보고서 자동 갱신 켜기 | 매일 아침 6시쯤 이번 달 보고서를 새로 고침. 매월 1~3일에는 지난달 것도 마무리 |
| 자동 갱신 끄기 | 위 자동 실행 중지 |

앱의 **보고서 › 월간** 화면에서 «보고서 탭 만들기» 버튼으로도 만들 수 있습니다.

보고서 탭 내용: 요약(점검률 · 빠진 평일 · 이상 건수 · 사진 수 · 눈에 띄는 변화) → 항목별 요약 표 → 이상 · 사진 목록 → 날짜별 값 표 → 숫자 항목별 선 그래프.

**구글 슬라이드에 붙이기**: 그래프 클릭 › 복사 › 슬라이드에 붙여넣기 › «스프레드시트에 연결». 보고서를 다시 만들면 그래프는 고쳐 쓰므로 슬라이드에서 «업데이트»만 누르면 최신 숫자로 바뀝니다.

## 사진이 시트에 보이는 방식

현장에서 «어? 이상한데» 싶으면 어느 항목에서나 📷 를 누를 수 있고, 점검표에 없는 것은 화면 아래 «점검표에 없는 이상 발견» 에서 찍습니다.

1. **점검표 칸**: 값은 그대로 두고 칸 배경만 연한 주황. 칸 메모(노트)에 «📷 사진 N장 · 점검자 시각», 한 줄 설명, 사진 링크
2. **«_사진기록» 탭**: 사진 한 장 = 한 줄 (날짜 · 시각 · 점검표 · 항목 · 그때 값 · 메모 · 점검자 · 칸 안 미리보기 · «열기»)
3. **드라이브**: «데일리체크 사진 / 탭이름» 폴더에 원본 (날짜 · 시간 · 점검자 워터마크)
4. 점검표에 «특이사항» 행이 없으면 처음 «이상 발견» 을 저장할 때 점검자 행 위에 자동으로 생깁니다. 이 행은 시트 구조가 바뀌는 것이라 앱의 «변경 확인»에 한 번 뜰 수 있습니다 (승인하면 끝).

사진은 외부에 공개되지 않습니다. 미리보기는 스크립트가 그림을 칸 안에 직접 넣는 방식입니다.

## 알아 둘 것

- 현장 직원은 구글 계정이 없어도 됩니다. 스크립트가 시트 주인 권한으로 기록합니다.
- 사진은 내 구글 드라이브 «데일리체크 사진 / 탭이름» 폴더에 저장되고, 시트 칸에 메모(노트)로 링크가 붙습니다.
- 인터넷이 없을 때 입력한 것은 휴대폰에 보관했다가 연결되면 자동으로 시트에 들어갑니다.
- 시트에서 고친 점검항목은 «변경 확인»에서 승인하면 반영됩니다. (위 설명 참고)
- **스크립트를 고친 뒤에는** 배포 › 배포 관리 › ✏️ › 버전: 새 버전 › 배포 (주소는 그대로 유지됨)
- 비밀번호를 아는 사람만 기록할 수 있습니다. 주소와 비밀번호를 외부에 공유하지 마세요.
